# Syncro-OS
Syncro OS adalah platform operasional bisnis terintegrasi yang menghubungkan landing page, pemesanan online, pengadaan bahan baku, manajemen stok, perhitungan HPP otomatis, penjualan, biaya operasional, laporan keuangan, dan dashboard bisnis dalam satu sistem. Sistem dirancang untuk membantu UMKM kuliner mengelola bisnis secara real-time.
